Design a finite state machine (FSM) for a serial receiver using a 1-start bit, 8-data bit, and 1-stop bit asynchronous serial communication protocol. The FSM operates on a synchronous clock (clk) and has an active-high synchronous reset (reset). The input 'in' represents the incoming serial data stream. The FSM must identify the start bit (0), sample the subsequent 8 data bits, and verify the stop bit (1). The FSM outputs a correctly received data byte on 'out_byte' and asserts 'done' high for one clock cycle when a valid byte is received. 'out_byte' is valid when 'done' is asserted and is don't-care otherwise. The serial protocol transmits the least significant bit (LSB) first. The FSM must handle framing errors. If a stop bit is not detected at the expected time, the FSM enters an error state and waits for a logic 1 to be detected, which it then interprets as the start of a new byte. The idle state is represented by a logic 1 level on the serial line. The receiver must differentiate between an idle state and a stop bit, which is also a logic 1, by the timing and the presence of a preceding start bit.
