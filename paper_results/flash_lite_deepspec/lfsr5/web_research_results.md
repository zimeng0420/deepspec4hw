## Result 1

A Linear Feedback Shift Register (LFSR) is a shift register whose input bit is a linear function of its previous state. The most common linear function used is exclusive-OR (XOR). LFSRs are used in digital circuits to generate pseudo-random sequences.

**Concept Definitions:**

*   **Shift Register:** A cascade of flip-flops where the output of one flip-flop is connected to the input of the next. The number of flip-flops determines the length of the LFSR (n).
*   **Feedback Function:** A linear function (typically XOR gates) that determines the new input to the first flip-flop by comparing the present state of desired bits (taps) in the shift register. The feedback function is determined by the characteristic polynomial of the LFSR.
*   **Taps:** Specific bit locations in the shift register from which values are taken for use by the feedback function.
*   **Maximum-length LFSR:** An LFSR that cycles through all possible states (2<sup>n</sup> - 1) before repeating. The all-zeros state is never reached.
*   **Seed:** The initial value of the LFSR.

**Working Principles:**

1.  **Initialization:** The shift register is set to an initial non-zero state.
2.  **Clock Signal:** A clock signal launches or synchronizes the shifting process.
3.  **Shifting:** On each clock pulse, the register shifts its contents one bit to the right (or left).
4.  **Feedback Calculation:** The feedback function determines a new bit based on the state of the tapped bits. This new bit becomes the input to the shift register.
5.  **Iteration:** The process continues until the desired number of bits is shifted.

**Design Methods and Tap Selection Criteria:**

*   **Characteristic Polynomial:** The feedback function is determined by the characteristic polynomial of the LFSR. The taps are selected based on this polynomial.
*   **Primitive Polynomial:** A necessary and sufficient condition for an LFSR to be maximal length is that its corresponding polynomial is primitive.
*   **Tap Selection Rules:**
    *   The number of taps can be even.
    *   The set of taps should be setwise co-prime; there must be no divisor other than 1 common to all taps.
    *   The 'one' in the polynomial corresponds to the input to the first bit.
    *   The powers of the terms represent the tapped bits, counting from the left.
    *   The first and last bits are always connected as an input and output tap, respectively.
*   **Fibonacci LFSR:** The feedback bit is generated by an XOR operation on predetermined bits (taps) of the register and is clocked into the input of the first D-FF.
*   **Galois LFSR:** The taps are XORed with the output bit before they are stored in the next position. Galois LFSRs can compute more than one operation at a time, which can be faster.

**Best Practices:**

*   Choose taps carefully to ensure a maximal-length sequence.
*   Use a non-zero seed to initialize the LFSR.
*   Consider the application when choosing between Fibonacci and Galois configurations. Galois LFSRs are more efficient in hardware.
*   LFSRs are often used in hardware due to their speed and simplicity.
