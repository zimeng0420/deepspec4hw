## Result 1

Asynchronous and synchronous resets are fundamental concepts in digital circuit design, each with distinct characteristics and trade-offs.

**Definitions and Working Principles**

*   **Asynchronous Reset:** This type of reset operates independently of the clock signal. It uses a dedicated reset signal that can trigger the reset operation at any time, regardless of the clock cycle. When asserted, it forces the flip-flop into a known state immediately.
*   **Synchronous Reset:** This reset method synchronizes the reset operation with the clock signal. The reset signal is applied to the flip-flops at a specific point in the clock cycle, typically on the rising or falling edge.

**Design Methods**

*   **Asynchronous Reset:**
    *   The reset signal is added to the sensitivity list of the `always` block in Verilog.
    *   The reset signal is asserted immediately.
    *   The deassertion of the reset signal should be synchronized to the clock to avoid metastability.
*   **Synchronous Reset:**
    *   The reset signal is synchronized to the clock signal.
    *   The reset signal is asserted during a specific phase of the clock cycle.
    *   A balanced reset tree can be built to reduce fan-out and ease delay paths.

**Best Practices**

*   **Asynchronous Reset:**
    *   Synchronize the deassertion of the asynchronous reset to the clock.
    *   Use a reset synchronizer to safely synchronize the asynchronous reset signal to the clock domain.
    *   Consider the potential for timing hazards and metastability issues.
*   **Synchronous Reset:**
    *   Ensure the reset pulse width is long enough to be present during an active edge of the clock.
    *   Use a balanced reset tree to reduce fan-out.
    *   Synchronous resets are recommended for some designs where the reset is generated by internal conditions.

**Implementation for D Flip-Flop with Asynchronous Reset**

The following Verilog code implements a D flip-flop with a positive edge trigger and an asynchronous reset:

```verilog
module top_module (
	input clk,
	input d,
	input ar,
	output logic q
);

always @(posedge clk or negedge ar)
begin
    if (!ar)
        q <= 1'b0; // Asynchronous reset: active low
    else
        q <= d;
end

endmodule
```
