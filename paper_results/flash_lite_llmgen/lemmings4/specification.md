**Technical Specification: Lemmings Finite State Machine**

**1. Introduction**

This specification outlines the design of a Finite State Machine (FSM) that models the behavior of a Lemming in a 2D environment. The Lemming can walk left or right, change direction upon encountering obstacles, fall, dig, and splatter. The FSM is implemented using a Moore machine architecture.

**2. Functional Requirements**

*   **Walking:** The Lemming can walk either left or right.
*   **Direction Change:** The Lemming changes direction when bumped into an obstacle.
    *   `bump_left = 1`: Walk right.
    *   `bump_right = 1`: Walk left.
    *   If both `bump_left` and `bump_right` are 1, the direction is still switched.
*   **Falling:** When `ground = 0`, the Lemming falls and outputs "aaah!".
*   **Digging:** When `ground = 1` and `dig = 1`, the Lemming starts digging. Digging continues until `ground = 0`.
*   **Splattering:** If the Lemming falls for more than 20 clock cycles and then hits the ground (`ground = 1`), it splatters and ceases all activity.
*   **Precedence:** The following precedence rules apply:
    1.  Falling has the highest precedence.
    2.  Digging has the second highest precedence.
    3.  Direction change has the lowest precedence.
*   **Asynchronous Reset:** The `areset` signal resets the FSM to the "walk left" state.

**3. Inputs**

*   `clk`: Clock signal (required for state transitions and timing).
*   `areset`: Asynchronous reset signal (active high, edge-triggered).
*   `bump_left`: Input indicating a bump on the left side (1 = bump).
*   `bump_right`: Input indicating a bump on the right side (1 = bump).
*   `ground`: Input indicating the presence of ground (1 = ground, 0 = no ground).
*   `dig`: Input indicating the command to dig (1 = dig).

**4. Outputs**

*   `walk_left`: Output indicating the Lemming is walking left (1 = walking left).
*   `walk_right`: Output indicating the Lemming is walking right (1 = walking right).
*   `aaah`: Output indicating the Lemming is falling (1 = falling).
*   `digging`: Output indicating the Lemming is digging (1 = digging).
