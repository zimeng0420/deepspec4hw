*   8'h45: Key 0
*   8'h16: Key 1
*   8'h1e: Key 2
*   8'h26: Key 3
*   8'h25: Key 4
*   8'h2e: Key 5
*   8'h36: Key 6
*   8'h3d: Key 7
*   8'h3e: Key 8
*   8'h46: Key 9

If a match is found, the `out` output will be set to the corresponding 4-bit value (0-9), and the `valid` output will be set to 1. If no match is found, both `out` and `valid` will be set to 0.
