**4. Detailed Design**

*   **Flip-Flop Implementation:**  While the code uses `reg` variables, the underlying hardware will be synthesized into flip-flops.  The `always_ff` block ensures this.
*   **Counting Logic:** The counter increments on each rising edge of the clock, unless the reset is asserted.
*   **Reset Logic:** When the `reset` input is high, the counter is synchronously reset to 0.
*   **Wrap-Around Logic:** When the counter reaches 9 (1001), the next clock cycle will reset it to 0.  This is achieved by checking if the current state is 9 and resetting the counter in that case.

    output reg [3:0] q

    end
