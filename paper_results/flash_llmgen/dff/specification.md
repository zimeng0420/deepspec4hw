**Technical Specification: Single D Flip-Flop**

**1. Introduction**

This document specifies the design and implementation of a single D flip-flop using Verilog. The D flip-flop is a fundamental building block in digital logic circuits, used for storing a single bit of data. This implementation will be a positive-edge triggered D flip-flop.

**2. Functional Description**

The D flip-flop captures the value of the input `d` at the rising edge of the clock signal `clk` and stores it in the output `q`.  The output `q` retains its value until the next rising edge of the clock.

*   **Positive-Edge Triggered:** The flip-flop updates its output `q` only on the rising edge (transition from low to high) of the clock signal `clk`.
*   **Data Input (d):** The value present at the `d` input at the rising edge of the clock is stored in the flip-flop.
*   **Clock Input (clk):** The clock signal that triggers the data capture.
*   **Output (q):** The stored value of the data input `d`.

**3. Module Definition**

```verilog
module top_module(
	input clk,
	input d,
	output reg q);

endmodule
```

**4. Detailed Design**

The D flip-flop will be implemented using a non-blocking assignment within an `always` block triggered by the positive edge of the clock.

```verilog
module top_module(
	input clk,
	input d,
	output reg q);

  always @(posedge clk) begin
    q <= d;
  end

endmodule
```
