    input clk,
    input reset,
    input [31:0] in,
    output reg [31:0] out);

  reg [31:0] prev_in;

  always @(posedge clk) begin
    if (reset) begin
      out <= 32'b0;
    end else begin
      for (int i = 0; i < 32; i++) begin
        if (prev_in[i] == 1 && in[i] == 0) begin
          out[i] <= 1'b1; // Capture the 1-to-0 transition
        end
      end
    end
    prev_in <= in; // Store the current input for the next clock cycle
  end

endmodule

**4. Detailed Design Description**

*   **`prev_in` Register:** A 32-bit register `prev_in` is used to store the value of the input vector `in` from the previous clock cycle. This allows for comparison between the current and previous input values to detect 1-to-0 transitions.
*   **`always @(posedge clk)` Block:** This block describes the sequential logic that executes on the rising edge of the clock.
*   **Reset Logic:**  The `if (reset)` condition checks if the reset signal is asserted. If it is, the output register `out` is set to all zeros, clearing any previously captured transitions.
*   **Transition Detection and Capture:** The `else` block contains the core logic for transition detection.  A `for` loop iterates through each bit of the input vector. Inside the loop, the condition `(prev_in[i] == 1 && in[i] == 0)` checks if a 1-to-0 transition has occurred for the `i`-th bit. If a transition is detected, the corresponding bit in the output register `out[i]` is set to '1'.  Crucially, once a bit in `out` is set to '1', it remains '1' until the reset signal is asserted.
*   **Updating `prev_in`:** After the transition detection and capture logic, the `prev_in` register is updated with the current value of the input vector `in`. This ensures that the `prev_in` register always holds the value of the input from the previous clock cycle.
