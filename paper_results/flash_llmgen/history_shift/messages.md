**Technical Specification: 32-bit Global History Shift Register with Rollback**

**1. Introduction**

This document specifies the design of a 32-bit global history shift register used in a pipelined processor to track branch prediction history. The register supports shifting in new branch prediction results and rolling back to a previous state in case of a branch misprediction.

**2. Functional Requirements**

*   **Global History Tracking:** The register maintains a 32-bit history of recent branch outcomes.
*   **Prediction Update:** When a branch prediction is made (`predict_valid = 1`), the `predict_taken` signal (representing whether the branch was predicted taken or not taken) is shifted into the least significant bit (LSB) of the history register.  The existing history is shifted to the left.

*   **Asynchronous Reset:** An asynchronous reset (`areset`) sets the history register to all zeros.
*   **Output:** The current value of the history register is available at the `predict_history` output.

**4. Detailed Design**

The design uses a register (`history`) to store the 32-bit global history.  The logic is implemented within an `always_ff` block triggered by the positive edge of the clock.

*   **Asynchronous Reset:** The `areset` signal has the highest priority. When asserted, the `history` register is immediately reset to zero.
*   **Misprediction Handling:** If `train_mispredicted` is asserted, the `history` register is loaded with the concatenated value of `train_history` and `train_taken`.
*   **Prediction Update:** If `predict_valid` is asserted and `train_mispredicted` is *not* asserted, the `history` register is updated by shifting in `predict_taken` from the LSB.

**5. Verilog Code**

```verilog
module top_module
(
    input clk,
    input areset,
    input predict_valid,
    input predict_taken,
    output logic [31:0] predict_history,

    input train_mispredicted,
    input train_taken,
    input [31:0] train_history
);

    logic [31:0] history;

    always_ff @(posedge clk, posedge areset) begin
        if (areset) begin
            history <= 32'b0;
        end else if (train_mispredicted) begin
            history <= {train_history[30:0], train_taken};
        end else if (predict_valid) begin
            history <= {history[30:0], predict_taken};
        end
    end

    assign predict_history = history;

endmodule
```
