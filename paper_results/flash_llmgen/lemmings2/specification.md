**Technical Specification: Lemmings Finite State Machine**

**1. Introduction**

This document specifies the design of a finite state machine (FSM) implemented in Verilog to model the behavior of a Lemming in a 2D environment. The Lemming can walk left or right, change direction upon collision with obstacles, and fall when the ground disappears. The FSM is a Moore machine, meaning the outputs are solely dependent on the current state.

**2. Functional Requirements**

*   **Walking:** The Lemming can walk either left or right. Only one of `walk_left` or `walk_right` can be asserted (logic 1) at any given time.
*   **Direction Change:**
    *   If `bump_left` is asserted, the Lemming changes direction to walk right.
    *   If `bump_right` is asserted, the Lemming changes direction to walk left.
    *   If both `bump_left` and `bump_right` are asserted, the Lemming changes direction (either left to right or right to left).
*   **Falling:**
    *   When `ground` is deasserted (logic 0), the Lemming enters a falling state and asserts `aaah`.
    *   While falling, `walk_left` and `walk_right` are deasserted.
    *   Bumps during falling do not affect the walking direction.
    *   The walking direction is preserved during the fall.
*   **Ground Reappearance:**
    *   When `ground` is asserted (logic 1) while the Lemming is falling, the Lemming exits the falling state.
    *   The Lemming resumes walking in the same direction it was walking before the fall.
*   **Reset:**
    *   The `areset` signal asynchronously resets the FSM to the walking left state.

**7. Verilog Implementation**

```verilog
module top_module (
    input clk,
    input areset,
    input bump_left,
    input bump_right,
    input ground,
    output walk_left,
    output walk_right,
    output aaah
);

  // Define the states
  localparam IDLE       = 2'b00;
  localparam WALK_LEFT  = 2'b01;
  localparam WALK_RIGHT = 2'b10;
  localparam FALLING    = 2'b11;

  // State register
  reg [1:0] current_state;
  reg [1:0] next_state;

  // State transition logic
  always @(*) begin
    case (current_state)
      IDLE: begin
        next_state = WALK_LEFT; // Always starts walking left
      end
      WALK_LEFT: begin
        if (!ground) begin
          next_state = FALLING;
        end else if (bump_right) begin
          next_state = WALK_RIGHT;
        end else begin
          next_state = WALK_LEFT;
        end
      end
      WALK_RIGHT: begin
        if (!ground) begin
          next_state = FALLING;
        end else if (bump_left) begin
          next_state = WALK_LEFT;
        end else begin
          next_state = WALK_RIGHT;
        end
      end
      FALLING: begin
        if (ground) begin
          // Restore previous walking direction
          if (current_state == FALLING) begin
            if ($past(current_state == WALK_LEFT)) begin
              next_state = WALK_LEFT;
            end else if ($past(current_state == WALK_RIGHT)) begin
              next_state = WALK_RIGHT;
            end else begin
              next_state = WALK_LEFT; // Default to left if previous state unknown
            end
          end else begin
            next_state = WALK_LEFT; // Default to left if previous state unknown
          end
        end else begin
          next_state = FALLING;
        end
      end
      default: begin
        next_state = IDLE;
      end
    endcase
  end

  // State update logic
  always @(posedge clk or posedge areset) begin
    if (areset) begin
      current_state <= IDLE;
    end else begin
      current_state <= next_state;
    end
  end

  // Output logic (Moore machine)
  assign walk_left  = (current_state == WALK_LEFT);
  assign walk_right = (current_state == WALK_RIGHT);
  assign aaah       = (current_state == FALLING);

endmodule
```
