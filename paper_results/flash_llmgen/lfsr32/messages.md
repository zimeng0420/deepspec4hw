**4. Detailed Design**

The Galois LFSR will be implemented using a 32-bit register (`q`) and XOR gates to provide the feedback. The XOR gates will be placed at the tap positions.

*   **Register:** `q[31:0]` - Stores the current state of the LFSR.
*   **Feedback Logic:** The next state of the LFSR is determined by XORing the output bit (LSB) with the bits at the tap positions.  The result of the XOR operation is then fed back into the MSB of the register.  The other bits are shifted.

The following equation describes the next state of the LFSR:

```
next_q[31] = q[0] ^ q[1] ^ q[21] ^ q[31]; // MSB
next_q[30:0] = q[31:1]; // Shift the rest of the bits
```
