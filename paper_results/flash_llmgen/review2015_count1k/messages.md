**5. Verilog Code**

```verilog
module top_module(
    input clk,
    input reset,
    output reg [9:0] q
);

  always @(posedge clk) begin
    if (reset) begin
      q <= 0;
    end else begin
      if (q == 999) begin
        q <= 0;
      end else begin
        q <= q + 1;
      end
    end
  end

endmodule
```

**6. Explanation**

*   **`module top_module(...)`**: Defines the module with the specified inputs and output.
*   **`always @(posedge clk)`**:  This block is triggered on the rising edge of the clock signal.
*   **`if (reset)`**: Checks if the reset signal is high. If it is, the counter `q` is set to 0.  This is the synchronous reset.
*   **`else`**: If the reset signal is not high, the counter proceeds with its normal counting operation.
*   **`if (q == 999)`**: Checks if the counter has reached its maximum value (999).
*   **`q <= 0`**: If the counter has reached 999, it is reset to 0 on the next clock cycle.
*   **`else q <= q + 1`**: Otherwise, the counter is incremented by 1.
