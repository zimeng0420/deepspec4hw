**4. Hardware Design (Verilog Code)**

```verilog
module top_module(
    input clk,
    input load,
    input [9:0] data,
    output tc
);

  reg [9:0] counter;
  reg tc_internal; // Internal signal for tc

  always @(posedge clk) begin
    if (load) begin
      counter <= data;
      tc_internal <= 0; // Reset tc when loading a new value
    } else begin
      if (counter > 0) begin
        counter <= counter - 1;
        tc_internal <= 0; // tc is low while counting
      } else begin
        counter <= 0; // Stay at 0 once reached
        tc_internal <= 1; // tc is high when count is 0
      end
    end
  end

  assign tc = tc_internal; // Assign internal signal to output

endmodule
```

**5.  Detailed Explanation**

*   **`module top_module(...)`**: Defines the module with the specified input and output ports.
*   **`reg [9:0] counter;`**: Declares a 10-bit register named `counter` to store the current count value.  It's a `reg` because its value is updated within an `always` block.
*   **`reg tc_internal;`**: Declares a register to hold the value of the terminal count signal. This is necessary because the output `tc` is assigned combinatorially from this register.
*   **`always @(posedge clk)`**:  This block executes on the rising edge of the clock signal.
*   **`if (load)`**:  If the `load` signal is high, the counter is loaded with the value from the `data` input.  Crucially, `tc_internal` is reset to 0 when a new value is loaded. This ensures that `tc` is only asserted *after* the countdown reaches zero, not immediately after loading.
*   **`else`**: If the `load` signal is low, the counter decrements.

    *   **`else`**: If the counter is already 0, it remains at 0, and `tc_internal` is set to 1. This implements the "stall" behavior.
*   **`assign tc = tc_internal;`**:  This line continuously assigns the value of the internal `tc_internal` register to the output `tc`.  This is a *combinational* assignment, meaning `tc` will immediately reflect any changes to `tc_internal`.
