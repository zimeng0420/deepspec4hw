## Result 1

When implementing synchronous resets in digital circuits, several design considerations come into play. Synchronous resets are asserted in sync with the clock to reset flip-flops.

Here's a breakdown of key aspects:

**1. Definition and Working Principle**

*   **Synchronous Reset:** A synchronous reset is only recognized at the active clock edge. The reset signal is sampled on the clock's rising edge. The reset operation occurs at a specific point in time, synchronized with the clock signal.

**2. Advantages**

*   **Improved Stability:** Synchronizing the reset operation with the clock signal helps avoid glitches and erratic behavior that can occur with asynchronous resets.
*   **Consistent Behavior:** Synchronous resets ensure the reset operation occurs at a known and predictable point in the clock cycle.
*   **Avoids Timing Hazards:** Synchronizing the reset signal to the clock helps avoid timing hazards and metastability issues that can arise with asynchronous resets.
*   **Design Closure:** Synchronous resets allow for cleaner timing and easier design closure, especially in FPGA or ASIC designs where clock control is reliable.
*  **Filtering Glitches:** The clock acts as a filter for small reset glitches. However, metastability can occur if glitches happen near the active clock edge.

**3. Disadvantages**

*   **Clock Dependency:** A clock must be present for the reset signal to have any effect.
*   **Routing Problems:** Global synchronous resets can create routing problems that lead to sub-optimal timing results. Routing a single reset signal to all locations on a chip within one clock cycle can consume significant routing resources.
*   **Potential Complexity:** Synchronous resets may require careful consideration of timing constraints and can be more complex in multi-clock domain systems.

**4. Design Considerations**

*   **Timing Constraints:** Synchronous resets rely on the clock signal to synchronize the reset operation with other circuit operations.
*   **Metastability:** Synchronous resets can help avoid metastability issues.
*   **Reset Pulse Width:** Synchronous resets may need a pulse stretcher to guarantee a reset pulse width wide enough to ensure the reset is present during an active edge of the clock.
*   **Internal Resets:** In some designs, the reset must be generated by a set of internal conditions. A synchronous reset is recommended for these types of designs because it will filter the logic equation glitches between clocks.
*   **HDL Coding Style:** The coding style to model the reset should be an if/else priority style with the reset in the if condition and all other combinational logic in the else section.

**5. Alternative Resetting Techniques**

*   **Asynchronous Reset:** Asynchronous resets offer an immediate system initialization. However, to avoid glitches, a reset synchronizer should be implemented.
*   **Asynchronous Reset with Synchronous Release:** This approach combines the immediate reset capability of asynchronous resets with the controlled release timing of synchronous resets.

**Regarding the LFSR Implementation**

*   **Galois LFSR:** In a Galois LFSR, bit positions with a "tap" are XORed with the output bit to produce its next value, while bit positions without a tap shift.
*   **Maximum-Length LFSR:** A maximum-length LFSR of *n* bits cycles through 2^*n*-1 states before repeating. The all-zeros state is typically avoided as the register can get stuck in this state.
*   **Taps:** The arrangement of taps for feedback in an LFSR can be expressed as a polynomial. The LFSR is maximal-length if and only if the corresponding feedback polynomial is primitive over the Galois field GF(2).
* The number of taps should be even, and the set of taps should be setwise co-prime.
