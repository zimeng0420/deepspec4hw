## Result 1

The principles of implementing a synchronous reset in Finite State Machines (FSMs) involve several key aspects:

**Concept and Working Principle**
A synchronous reset ensures that the FSM returns to a known initial state on an active clock edge. The reset signal's effect on the FSM's state register is synchronized with the clock signal. The state register holds the current state and updates on clock edges or resets to a defined state.

**Implementation**
1.  **State Representation:** States are represented using parameters or local parameters for readability.
2.  **Reset Logic:** The reset is applied to the flip-flop as part of the combinational logic that generates the d-input to the flip-flop.
3.  **Coding Style:** Model the reset using an `if/else` priority style, with the reset condition in the `if` section and other combinational logic in the `else` section.
4.  **Multiplexers:** Synchronous Reset can be implemented by inserting 2-to-1 multiplexers that drive the D inputs of every flip-flop. When the reset is asserted, the multiplexers steer a logic zero into the D inputs of each flip-flop.

**Advantages**
*   **Synchronous Operation**: It helps ensure the circuit is 100% synchronous.
*   **Glitch Filtering**: The clock acts as a filter for small reset glitches. However, metastability can occur if glitches happen near the active clock edge.
*   **Smaller Flip-Flops**: Synchronous reset logic can synthesize to smaller flip-flops, especially if the reset is gated with the logic generating the d-input.

**Disadvantages**
*   **Pulse Stretching**: Synchronous resets might need a pulse stretcher to guarantee the reset pulse width is wide enough to ensure the reset is present during an active clock edge.
*   **Logic Synthesis**: Logic synthesis might not easily distinguish the reset signal from other data signals.

**Additional Considerations**

*   **Metastability**: Synchronous resets avoid metastability problems.
*   **Reset Deassertion**: Reset deassertion should always occur with respect to the clock.
*   **FPGA Initialization**: Xilinx FPGAs are designed so that on power-up, the D flip-flops initialize to logic 0.
*   **Alternatives to Reset**: Relying on signal and output initialization values is valid if the machine meets design requirements.
*   **Internal Resets**: In some designs, the reset must be generated by a set of internal conditions. A synchronous reset is recommended for these types of designs because it will filter the logic equation glitches between clocks.

Based on the search results, here is a Verilog implementation of a finite-state machine that searches for the sequence 1101 in an input bit stream. When the sequence is found, it sets `start_shifting` to 1 and remains asserted until reset. Reset is active-high synchronous.

```verilog
module top_module(
    input clk,
    input reset,
    input data,
    output start_shifting);

  reg start_shifting;
  reg [2:0] state;

  // Define state values
  localparam S_IDLE = 3'b000;
  localparam S_1    = 3'b001;
  localparam S_11   = 3'b010;
  localparam S_110  = 3'b011;
  localparam S_1101 = 3'b100;
  localparam S_FOUND = 3'b101;

  always @(posedge clk) begin
    if (reset) begin
      state <= S_IDLE;
      start_shifting <= 1'b0;
    end else begin
      case (state)
        S_IDLE: begin
          if (data == 1'b1) begin
            state <= S_1;
          end
        end
        S_1: begin
          if (data == 1'b1) begin
            state <= S_11;
          end else begin
            state <= S_IDLE;
          end
        end
        S_11: begin
          if (data == 1'b0) begin
            state <= S_110;
          end else begin
            state <= S_11;
          end
        end
        S_110: begin
          if (data == 1'b1) begin
            state <= S_1101;
          end else begin
            state <= S_IDLE;
          end
        end
        S_1101: begin
          state <= S_FOUND;
          start_shifting <= 1'b1;
        end
        S_FOUND: begin
          start_shifting <= 1'b1; //Stays high until reset
        end
        default: state <= S_IDLE;
      endcase
    end
  end
endmodule
```
